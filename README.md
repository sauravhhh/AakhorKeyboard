# Aakhor Keyboard

A simple, fast Android soft keyboard — no network, no data collection. Nothing you type ever leaves your phone.

**Layouts**
- Alphabet — QWERTY with one-tap shift
- Numbers & symbols — `?123` page plus a second `#+%` page (€ £ ¥ © ® ™ …)
- Emoji picker — 80 common emoji

**Install**
1. Download `aakhor-keyboard-v1.0.apk` from [Releases](../../releases) (or tap the one-click link below)
2. Install the APK, then open **Aakhor Keyboard** from your app list
3. Tap **Enable**, turn on Aakhor Keyboard, then tap **Switch** and choose it
